## 1. 目标与继承关系

以已经过审计的第十五阶段实现为起点，统一问题视图的依赖追踪、即时失效与按价值刷新。
高频明确问题优先复用结构化答案；开放式请求保留必要检索与推理。成功标准是相同质量、安全和 freshness 下
全链路成本有证据改善，不能仅凭少调用一次路由模型宣称成功。

## 2. 架构与实现位置

完整架构、写入刷新与读取图位于[设计第 4 节](../AGENT_MEMORY_DESIGN_V7.0.0.md#algorithm-architecture)。
按事务、状态机与变化原因组织模块，保持模块化单体，不为每个名词创建目录/服务。

| 能力 | 复用位置 | 关键约束 |
| --- | --- | --- |
| 来源、抽取、证据与双时态 | capture / consolidation / domain / admission 与现有后端 | 语义接纳仍由内核判定；新领域需要相应证据合同 |
| 问题定义/实例与计算 | derived | 结构化 full 为 oracle；业务模板与队列调度分开 |
| typed edges / query subscription | derived + operations 后端 UoW | old/new 成员与空结果覆盖；事务屏障先于后台 |
| 合并/热冷/公平/定时 | operations + 现有 FacetRefreshQueue/宿主 worker | 固定 claim、后继责任、due 持久化、共享预算 |
| 内容/证书与 CAS | derived + 存储 UoW | 原生成谱系不可替换；证明传播与内容重算分开 |
| 路由/答案复用 | retrieval + 受治理模型端口 | 明确问题确定性选路；输入、dispatch、交付分别守卫 |
| 协议与装配 | runtime/kernel、SDK/MCP、PG adapter | 薄门面、版本化投影；未实现能力不宣告支持 |
| 测量与发布 | evaluation、运维 trace、独立验证记录 | 生产不导入评测；前后台费用对账，质量非退化 |

## 4. 关键实施决定

1. **先 full，再 delta。** 首先缩小受影响视图范围与合并重复计算，再优化单视图计算。delta 不支持的变更完整重建。
2. **三类依赖保留。** 支持资格、实际处理输入与查询完整性分别记录，共用反查基础设施；查询范围包括空结果及资格会变的候选。
3. **内容与证明分离。** 新验证来源不替换旧生成输入；同文本但私有旧谱系受限时必须新生成。
4. **有限目标与当前性分离。** 旧 exact 回执不改义；新 coverage 合同可被兼容后继覆盖，当前读取另外检查版本/时间/安全。
5. **结构化业务合同先行。** 无完成记录不是已知未完成；无风险命中不是现实无风险；必要字段缺失返回未知或部分。
6. **按收益维护。** 冷视图只失效，热门下游可临时拉起冷父；公平与预算统一，前台不旁路。
7. **真实成本后验收。** 模型桩验证合同，真实模型/许可数据验证质量与成本；未知费用不能记录为零。

## 5. 迁移与回滚

先注册新 schema/capability 和保守 scope/query 屏障，再适配全部写入、删除与恢复入口，回填订阅并验证。
旧版本来源/Atom/回执与序列化保持；新证书仅在足够谱系与完整性证明下产生。
迁移期间采用保守失效，不能为了继续命中而忽略还没完成的索引覆盖。

旧租约按旧合同完成或可审计交接；旧进程不能处理它不识别的新对象/回执。
回滚先关闭新能力，再按需排空/封存责任并保持删除屏障；旧备份恢复必须重放当前权威删除记录。
擦除覆盖内容、证书、缓存、订阅键和敏感热度统计，保留最小无正文 tombstone。
每次实施记录单独说明新增数据、升级方式、开关、失败恢复和不可逆边界。

## 6. 验证与度量

- 每批运行专项和受影响回归，包括 SQLite 与真实 PostgreSQL 的适用合同；不机械逐步全量。
- 最终 B6 执行完整仓库/扩展包、构建安装、真实进程强杀、跨连接竞争、受控备份恢复及兼容矩阵。
- 继承 R/N 的 66 项与新增 Q7 的 32 项按能力逐项映射。支持能力必须全部通过其适用项；
  unsupported/deferred、未运行、数据不足分别报告，不能计入支持能力通过率。
- 有效质量、证据覆盖、时效、安全、延迟与费用共同验收。以固定负载比较按需 full、合并 full、delta/证明复用、精确缓存。
- 统计冷启动/注册/预热、写入、依赖、后台、前台、失败/重试及未决债务；按全部请求与有效回答双分母报告。
- 数据/模型/供应商/裁判/阈值事先冻结，缺少真实配置时可完成协议切片，但不能宣称生产效果或启用未经验证的模型能力。

不预设虚构吞吐量、工期、节省百分比和最优阈值；在 B0 的 AcceptanceProfile 中声明待校准项并记录选择依据。

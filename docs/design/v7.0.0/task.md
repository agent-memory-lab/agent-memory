## 1. 使用规则

任务状态与运行证据分开。TODO → IN_PROGRESS → DONE 需要该任务声明范围内的实现、必要测试、迁移与文档；
可选能力可明确 DEFERRED，但不能把延期计为通过。用户已要求最后完整测试，实施中按影响面验证，最终按 [plan](plan.md) 集成验收。
每次交付追加代码 SHA、实际命令/结果、未覆盖范围和独立记录；设计正文冻结，台账独立增加 revision。

本轮开始 B0 合同与基线实施；状态按实际切片更新，未完成任务不提前标 DONE。既有 44 项状态快照见第 4 节；
它们的详细证据仍由 [AM61 台账](../v6.1.0/task.md) 维护。新条目不删除旧欠账，旧条目也不能重复计算为新增交付。
任务依赖指适用的明确能力切片，不能以依赖任务整体仍在进行为理由无限阻塞，亦不能跳过必要前置合同。
同批新增写入同时完成读取/失效/权限/擦除/恢复，T14/T15 不是最后才开始的补救工作。

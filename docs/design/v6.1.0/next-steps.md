   指定配置版本，计算旧贡献退出/新贡献进入；继续保留原始来源、历史认知、CAS 与删除屏障。
   **整来源 primary 模式已实现并验证**，见 [第一阶段记录](stage-01.md)。部分覆盖与复杂合成贡献保持关闭。
2. **字段/时间支持与条件投影（T07–T11）。** 加可信 QueryContext、条件三值求值与适用域；
   跨来源 AND 取有效区间交、OR 保留区间并及间隙；加入来源族与业务版本，避免伪独立佐证。
   **同 scope 单值事实/偏好的核心闭环已实现**，见 [第二阶段记录](stage-02.md)。候选保留待决，显式上下文查询返回完整支持的条件投影；普通读取不暴露无条件 Claim。否定/约束合取/跨存储范围仍未启用。
3. **贡献级更正与撤回（T10/T12）。** 把终止依据与新值成立依据分开建模；完善 R06/R07：
   删除 B 的支持不能无依据复活 A；纠正 E1 不能误删独立 E2；跨槽事务未验收前保持关闭。
   **同 scope 同槽普通贡献切片已实现**，见 [第三阶段记录](stage-03.md)：原子更正/撤回、独立终止、显式连续性更正和擦除屏障；复杂合成贡献及跨槽仍关闭。
4. **运行恢复补齐（T17/T18/T22/T23/T24）。** 离线设备 purge 协调、多 producer 竞争、真实进程终止恢复、
   **首个运行恢复切片已验证**，见 [第四阶段记录](stage-04.md)：多 producer 跨连接竞争、真实 SIGKILL、
   双端显式启用的 SDK/MCP purge 同步。
   **有限捕获目标、跨请求发布汇总与 opt-in 取消处置已验证**，见 [第五阶段记录](stage-05.md)。
   **本地候选索引 outbox 与连续覆盖已验证**，见 [第六阶段记录](stage-06.md)：opt-in candidate-locator/1。
   **显式重处理目标入口已验证**，见 [第七阶段记录](stage-07.md)：固定请求、处理配置与 processing token。
   单请求多发布、通用刷新、外部/派生索引和权威删除日志备份回放仍待补。
5. **真实领域标注与启用门（T03/T05/T14/T38/T39）。** 固定可用真实对话、标注与配置，验证误接纳、覆盖与有效召回。
   合成夹具和确定性规则测试不等于生产抽取质量。

接入外部模型之前必须完成 B06 适用的输入/用途许可、dispatch、预算与交付守卫。
不另起调度服务、不扩控制台替代核心合同；每步继续测试旧 API 和双后端。

## 每一批都要持续完成的工作

- **T03/T05：真实 gold 与配置校准。** 补充合法可用的实际对话，固定标注、切分、裁判和配置；
  合成 17/20 数据持续做回归，不替代真实领域质量。未校准时不编造生产阈值。
- **T04/T24：故障与双后端。** 每个新增事务、状态和删除路径都有对应故障用例，必要时补真实进程终止/恢复测试。
  mock、进程内异常和真实外部调用分别报告。
- **T34/T38/T39：证据和发布门。** 每批接上其实际运行阶段的证据；安全、覆盖、质量、费用与延迟分别判断。
  该基础工作不能等 B08 才开始，B08 是扩展完整检索/Reflect 实验。
- **T44：运行说明。** 同步配置、迁移、支持矩阵、回滚、跳过项和失败恢复；记录设计/代码/数据/配置指纹。

下一次开发继续第四步的目标入口与运行合同：

1. **T16/T18/T22 索引 outbox 与发布覆盖。首个本地身份索引切片已完成**，见 [stage-06](stage-06.md)。连续覆盖/零输出/实际证明已验证；全文、向量、外部索引和规模优化仍按各自启用合同推进。
2. **T17/T18/T22 剩余目标与运行合同。** 显式 reprocess 目标入口已完成，见 [stage-07](stage-07.md)。下一切片优先实现通用资源刷新合并与运行中新工作；单请求多次发布仍待补；补充终止索引缺口的显式修复/stream rollover，不能把取消当作已可见、把旧正文改身份或换 epoch 重放。
3. **T23/T24 删除恢复回放。** 从权威最新删除记录恢复旧备份，覆盖日志缺失/回退、旧离线设备和多连接删除竞争；提供可重复操作步骤。
4. **T03/T05/T14/T38/T39 真实领域启用门。** 固定合法实际对话、标注、配置与阈值证据，再评价抽取质量和收益；外部模型另完成 B06 守卫。

前三步的未启用语义扩展继续依各自验收合同推进，不因运行可靠性通过而自动开放。
后续开发遵循用户最新要求：实现后运行新增专项及受影响接口回归，不默认执行全量测试；另有明确要求时再扩大测试范围。

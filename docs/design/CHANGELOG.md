## 6.0.0 — 2026-10-06

状态：PROPOSED_BASELINE。正文：[统一架构设计 v6.0.0](AGENT_MEMORY_DESIGN_V6.0.0.md)。
前序版本：[v5.0.0](AGENT_MEMORY_DESIGN_V5.0.0.md)。实现核对基线继续为 `5cff9f47b7061351fd725c3b8e0a89bf5cb51517`。
依据：[完整性与逻辑性审查](reviews/AGENT_MEMORY_DESIGN_V5.0.0_REVIEW_2026-10-06.md)的四项 P1 问题。

### 四项契约修订

- **R01 跨范围合成**：保留 slot 身份，增加逻辑属性键与可信 QueryContext；按谓词政策执行偏序覆盖、约束合取或成员合成。明确三值适用性、争议禁止伪回退、历史政策版本与当前安全约束。
- **R02 重处理替代**：区分 additive 与 replace_interpretation；按旧解释与新候选的联合清单逐项复核，在共享解释头上 CAS 原子切换。缺席不是反证，partial 不激活，其他来源支持与历史保留。
- **R03 输入和交付守卫**：任何模型调用前验证实际输入、当前访问与处理接收方权限，最终答案交付前复查。明确授权顺序、在途边界、默认缓冲及可选逐块授权流式输出。
- **R04 派生输入权限**：分开事实支持依赖与全部实际输入的 processing 依赖；多轮、缓存、增量块及页面结构传播输入约束，省略引用不能放宽受众。级别转换须独立授权和产物。

### 关联更新

- 更新模型、32 节中的相关流程、API 能力、迁移、P0–P6 依赖、需求映射；增加 INV-21–24 与 ADR-015–018。
- 新增 R01–R04 共 24 项必要验收及 3 个端到端组合案例；明确验收尚待运行实现。
- 新增 V5→V6 迁移契约：旧 input lineage 缺失时不得宣称严格 V6，按真实输入重建，不能从引用列表伪造完整清单。
- 派生权限从必要依据收紧至全部生成输入，涉及核心权限语义，按既有规则发布 MAJOR。
- 保留 v5.0.0 正文和 SHA-256；更新当前版本入口及机器清单。R05–R13 继续作为未关闭设计项跟踪。

本次交付为设计修订，未将新增能力登记为运行代码已实现或生产验收通过。

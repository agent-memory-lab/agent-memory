交付：逐项列出已有对象、可调用接口、实际调用链、持久化方式、权限来源和缺失行为；检查 publish_procedure 与 EvolutionEngine 之间是否存在绕过受控晋升的入口。

验收：新增、复用和迁移三类改动有明确清单；每项缺口映射到后续任务。状态：已完成，证据见 `IMPLEMENTATION_AUDIT.md`。

- [x] **T02 明确反馈关联与兼容契约**

优先级：P0。依赖：T01。位置：领域对象、序列化、端口及契约文档。

交付：确定 run/decision/outcome/evaluation/bundle 标识、记忆版本引用、奖励定义版本、幂等键、更正关系及 scope 校验规则；决定复用 EvaluationReport 还是新增有明确区别的反馈对象。

验收：定义重复同内容、重复不同内容、乱序、缺失评价、取消、超时、未知结果和跨作用域引用的返回行为；旧调用兼容及 schema 迁移策略有记录。状态：已完成，证据见 `FEEDBACK_CONTRACT.md`。

## M1 反馈闭环

- [x] **T04 补齐 SQLite 反馈存储与迁移**

优先级：P0。依赖：T02。位置：`src/agent_memory/sqlite.py`、存储端口和序列化。

交付：持久化关联标识、版本、更正和待关联状态；新增必要的 scope/关联索引、幂等约束及分页查询；沿用已有 evolution record 存储时明确兼容转换。

验收：旧数据库升级不丢数据；重复及并发写入结果一致；中途失败原子回滚；重启后引用和状态保持。状态：已完成，schema v2 及迁移、索引、分页、并发幂等、回滚和重启测试已通过。

- [x] **T05 建立可信反馈写入规则**

优先级：P0。依赖：T04。位置：`kernel.py` 与反馈扩展逻辑。

交付：校验 Decision、Outcome、Evaluation、Reward 的作用域、来源、引用和定义版本；对乱序反馈实施有界待关联机制，支持更正记录与超期终止。

验收：跨租户和不可信评价被拒绝；未知结果不计为失败；待关联反馈不影响候选晋升；重复反馈不重复累计。状态：已完成，覆盖 scope、评价者 allowlist、幂等冲突、pending TTL/容量及 unknown/cancelled/timed_out。

- [x] **T06 增加检索追踪与使用确认**

优先级：P0。依赖：T02、T04。位置：MemoryBundle、检索组装及追踪存储。

交付：可配置记录 bundle/request ID、返回记忆版本、策略版本、预算与裁剪摘要；由宿主明确上报使用项，未上报标记 unknown。

验收：追踪可关联决策，不把返回项自动视为使用项；关闭追踪不破坏既有检索；不复制全量记忆内容，记录大小受预算限制。状态：已完成，由 `RetrievalTrace` 和 bundle 使用校验实现。

- [x] **T07 提供简洁的本地与 SDK 反馈接口**

优先级：P0。依赖：T05、T06。位置：`runtime.py`、`packages/python-sdk`。

交付：基于已有 record_* 能力封装易用接入，支持结果收据、幂等重试和查询反馈状态；接口名称按 T02 冻结。

验收：一个 SQLite 示例完成 remember、recall、decision、outcome、evaluation 的持久化 round trip；无需手写 SQL 或引入外部服务。状态：已完成，本地 facade、Embedded SDK 和反馈收据查询已通过。

- [x] **T08 接通 Generic LangGraph 与 MCP 宿主映射**

优先级：P1。依赖：T07。位置：`src/agent_memory/adapters.py`、`packages/langgraph`、`packages/mcp-server`。

交付：按能力协商映射已有生命周期事件及反馈；MCP 的身份和 scope 从认证上下文获得，工具参数只承载任务数据。

验收：各适配器调用同一业务规则；不支持反馈的 Provider 给出明确降级；缺少评价的 session_end 不自动生成成功奖励。状态：已完成，Generic/LangGraph/MCP 共用 provider 规则并按 capability 降级。

- [x] **T09 完成反馈证据的删除与撤销传播**

优先级：P0。依赖：T05、T06。位置：forget、反馈引用和派生对象处理。

交付：来源真删除、更正或撤销后，清理敏感载荷，失效依赖评价及候选；只保留许可范围内的非敏感审计信息。

验收：删除后查询、候选生成、评价聚合及晋升均不能继续消费失效证据；部分来源删除与全部来源删除分别测试。状态：已完成，反馈链递归失效、敏感载荷清理、派生对象失效及候选晋升阻断测试已通过。

## M2 受控记忆进化

- [x] **T10 将完整反馈整理为 Episode 与 Procedure 候选**

优先级：P0。依赖：T05、T09。位置：已有 consolidation 与 `packages/evolution` 的 generator。

验收：重复任务不重复生成有效候选；失败轨迹不自动激活；来源缺失、权限不兼容或评价不完整的候选被拒绝或保留待处理。状态：已完成，严格反馈链、稳定 Episode/Procedure/Candidate ID、失败反例及幂等注册专项测试已通过。

- [x] **T11 完善 Procedure 评价与晋升权限**

优先级：P0。依赖：T10。位置：EvolutionEngine、policy、registry 和已有状态机测试。

交付：复用状态机，绑定候选版本、评测集/评价定义版本、评估者和审批者；明确宿主策略与能力要求。

验收：跳阶段、伪造评价、失效审批、错误版本及跨作用域晋升全部拒绝；同一晋升重试不会重复生效；合法路径可完成。状态：已完成，显式来源绑定、宿主 allowlist、限时审批、幂等晋升及旧库迁移测试已通过。

- [x] **T12 完善晋升部署与回滚一致性**

优先级：P0。依赖：T11。位置：Evolution registry、deployment、Procedure 检索。

交付：明确状态登记与生效指针切换的提交顺序、失败补偿及重启恢复；保留兼容版本与回滚原因。

验收：部署失败不留下假 active；回滚后新检索选择正确版本；进程中断可恢复，审计链完整；不声称撤销已执行的外部工具副作用。状态：已完成，scope 级活动指针、失败补偿、回滚清理及重启恢复测试已通过。

- [x] **T13 实现一个确定性检索策略候选闭环**

优先级：P1。依赖：T06、T11、T12。位置：检索融合/重排与可选 Evolution 扩展。

交付：只选择一组通道权重或预算分配参数作为候选，对照固定策略离线回放，由宿主标准决定生效；记录基线、候选及反馈版本。

验收：样本不足沿用基线；策略不能放宽 scope 或总预算；候选劣化可回退；报告样本数、评测条件及成本，不把相关性描述为因果收益。状态：已完成，固定反馈版本回放、预算/scope 门槛、成本报告、活动指针及回退专项测试已通过。
